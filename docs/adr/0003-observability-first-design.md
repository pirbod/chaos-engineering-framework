# ADR 0003: Observability-First Design

## Status

Accepted

## Context

Chaos testing is only useful when teams can detect and act on the resulting signals.

## Decision

Expose Prometheus metrics from the API and include Grafana, Datadog and alert examples focused on experiment outcomes, service risk and MTTD.

## Consequences

The platform demonstrates how reliability work becomes measurable and actionable rather than just a YAML delivery workflow.
